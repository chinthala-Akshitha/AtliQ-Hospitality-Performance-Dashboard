This project presents an interactive Power BI dashboard developed for AtliQ Hospitality to analyze hotel performance across multiple metrics and dimensions. 

The analysis spans three months and includes multiple hotels, booking platforms, and cities.

**📊 Key Features**

End-to-End Hospitality Analytics: Built a comprehensive Power BI dashboard to monitor revenue, occupancy, cancellations, and customer ratings.

Dynamic Filtering & Slicers: Enabled user-friendly filters by hotel name, category, city, room class, and booking platform.

Revenue Insights: Displayed monthly revenue distribution by hotel using stacked area charts.

Booking Platform Analysis: Compared Realization % and ADR (Average Daily Rate) by platform for actionable insights.

Trend Analysis: Visualized revenue trends over time (realized vs. generated) for forecasting.

KPI Metrics: Summarized key performance indicators like RevPAR, occupancy, cancellations, and average ratings.
